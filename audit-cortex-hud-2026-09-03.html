Security, NUI, and lifecycle notes

Passed

  • Server re-resolves NetworkGetEntityFromNetworkId, checks type 2, destroyed, lock, distance, speed, cooldowns, session token + notBefore/expiresAt, and entity identity at finish.
  • Clone QTE nonce binding, bounded rounds (1-4) and durations, cancel paths on move-away, every NUI callback answers exactly once.
  • No secrets in shared/client/NUI files; radio catalog pins its upstream commit; no remote ui_page.
  • Focus ownership is single-path: settings and move modes set and release SetNuiFocus; QTE never takes focus.
  • Stop cleanup restores DisplayHud/DisplayRadar, radio, weapons, minimap; server clears sessions on drop.

Watch items

  • Clone token uses math.random hex; acceptable inside a server-bound timed session, but prefer a longer nonce if tokens ever leave that binding.
  • Wait(200) inside the cortex-lib:settingsAction handler blocks that event briefly during move-mode switch; harmless but move to a thread if more steps are added.
  • Client smashVehicleWindow trusts the owner to execute the smash; correct for ownership, but treat a non-replicating owner as a visual desync to re-request, not a security failure.
  • Framework surface is standalone + qbx only; ESX/QBCore need bridge work despite some legacy event listeners.
Remediation in order

Fix these before release

  1. Key the standalone store by stable identity. Replace standaloneKeys[src][entity] with networkId (or plate + model), delete on finish/cancel/drop, and add a regression test that recycles the entity handle. File: modules/interactions/server.lua:105-153.
  2. Add the bucket guard to the door handler. Mirror resolveAccessVehicle lines 59-63 in cortex-hud:server:vehicleDoor. File: server.lua:224-271.
  3. Repair packaging. Remove web/node_modules from the resource tree, rebuild with bun install --frozen-lockfile; bun run build, re-run validate-resource.ps1 to zero errors, and align README with the chosen dist policy.
  4. Re-pin the radio icon. Run node scripts/generate-radio-icons.mjs, verify RADIO_19_USER.svg, re-run node --test tests/radio_icon_assets.test.mjs. Run the full suite under Bun, not plain Node.
  5. Sync manifest exports. List every runtime exports(...) actually registered (HUD, seatbelt, stall, harness, cruise, radio, effects, settings) or deliberately narrow the public API and remove the rest from README.
  6. Verify the minimap asset in-game. Confirm squaremap.ytd replaces the mask; if a placeholder, replace it or document textureReplacement.enabled = false.
Gradient/transition findings: keep the four mask usages only with a recorded waiver and screenshots, otherwise rebuild dividers and fades from solid fills or SVG geometry. Scope the ten transition: all rules to named properties.
